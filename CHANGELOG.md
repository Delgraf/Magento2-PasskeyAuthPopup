# Changelog

All notable changes to this module are listed here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-11-11

### Added

- Passkey sign-in button in Magento's authentication popup.
- Passkey autofill on the popup's email field, armed when the popup opens.
- Page reload and private-content refresh after a passkey sign-in.
- Removal on the login and checkout pages, where `mage-os/module-passkey-auth` already handles passkeys.
